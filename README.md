# PlanCraft 3D

A free home planning tool that runs in your browser. Draw a plan in 2D, walk through it in 3D, and estimate the cost using Bangladesh material prices.

**Live site:** https://abdullah-jewel.github.io/Building-PlanCraft-2D-3D/
**Open the planner:** https://abdullah-jewel.github.io/Building-PlanCraft-2D-3D/app/

## Features
- 2D blueprint and first-person 3D view, walls at any angle (0.01 degree steps)
- Doors, windows, furniture, floor finishes, glass stair railings
- Up to ten floors, with flat, hip and gable roofs
- Cost estimate in BDT, USD, INR or EUR with editable local prices
- Rebar schedule by diameter (10, 12, 16 and 20 mm)
- Column grid generator, plot and setback lines
- North arrow and sun shadow study
- Electrical and plumbing layers with a pipe tool
- Dimension tool, plus PDF, PNG and DXF export
- Works on phones and computers, with a 3D quality setting

## Built with
React, Three.js, Tailwind CSS and jsPDF, in a single HTML file.

## Important
Cost figures are planning estimates, not quotations. Structural design, soil testing and building approvals must come from a licensed engineer or architect.
