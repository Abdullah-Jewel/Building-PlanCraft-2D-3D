# PlanCraft 3D website

Upload the CONTENTS of `dist/` to the root of your GitHub Pages repo (replace the old index.html; the planner now lives at /app/).

To change the domain, email or turn on ads: edit `site.config.json`, then run `python3 build.py` and upload `dist/` again.
- custom_domain: e.g. "plancraft3d.me" (creates the CNAME file)
- contact_email: your public contact address (shown on About, Contact, Privacy)
- adsense_enabled: set true only AFTER AdSense approves the site
